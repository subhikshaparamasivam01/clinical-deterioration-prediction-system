# 🏥 Patient Risk Checker

> **A smart healthcare risk assessment web application powered by Machine Learning.**

Patient Risk Checker is a **Flask-based web application** that analyzes clinical patient data and provides an estimated **risk percentage** with a clear **Low, Medium, or High** risk classification.

---

## ✨ Features

* 🩺 **Patient Risk Assessment**
* 🤖 **Machine Learning Prediction**
* 📊 **Risk Percentage**
* 🚦 **Low / Medium / High Risk Levels**
* 🎨 **Simple & Responsive Interface**
* 🔐 **Security-Focused Design**
* ⚡ **Fast Flask Backend**
* 📱 **Future Android App Support**
